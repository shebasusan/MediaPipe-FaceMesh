#  MediaPipe Face Mesh

A real-time face mesh detection project built using **Python**, **OpenCV**, and **MediaPipe**. This application captures live webcam video and detects facial landmarks, rendering a detailed mesh on the face.

---

##  Features

* Real-time face mesh detection
* 468 facial landmark points
* Webcam-based live tracking
* Fast and lightweight performance

---

##  Technologies Used

* Python
* OpenCV
* MediaPipe

---

##  How to Run

1. Clone the repository:

   ```
   git clone https://github.com/shebasusan/MediaPipe-FaceMesh.git
   cd MediaPipe-FaceMesh
   ```

2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

3. Run the project:

   ```
   python face_mesh_webcam - Copy.py
   ```

---

##  Applications

* Augmented Reality (AR)
* Facial feature tracking
* Virtual try-on systems
* Animation and gaming

  Face Mesh is used for:

* Detecting 468 facial landmark points in real time.
* Tracking facial features such as the eyes, eyebrows, nose, lips, jawline, and face contour.
* Creating AR filters (Snapchat/Instagram-style effects).
* Face alignment and face geometry estimation.
* Eye tracking and blink detection.
* Expression analysis (smile, mouth open, eyebrow movement).
* Virtual makeup and beauty filters.
* Head pose estimation.
* Face recognition preprocessing.

---

##  Output

The system will open your webcam and display a real-time face mesh overlay.
